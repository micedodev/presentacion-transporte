# DDO · Direct Delivery Optimization

Euskadiko bidesari eta aparkaleku kalkulagailuaren pitch-a (Ekingune Txurdinaga · ASIR).

Egileak: Aimar, Aitor, Markel eta Ibai.

## Nola ikusi

Ireki `index.html` nabigatzaile batean (Internet konexioarekin, animazioak eta letra-tipoak CDNetik kargatzen baitira).

- **→ / ↓ / Espazioa / PageDown**: hurrengo pantaila
- **← / ↑ / PageUp**: aurrekoa
- **F**: pantaila osoa

GitHub Pages aktibatuz gero (Settings → Pages → `main` adarra, `/root`), aurkezpena zuzenean ikus daiteke sarean.
